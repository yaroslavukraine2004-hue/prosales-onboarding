# Pro Sales Agency — Онбординг «Досьє продукту»

Веб-застосунок: кожному клієнту генерується окреме посилання, він проходить
15 розділів, усі відповіді й файли зберігаються, а ви бачите їх в адмін-панелі.

- **Форма клієнта:** `/f/{token}` (посилання створюється в адмінці)
- **Адмін-панель:** `/admin` (захищена паролем)

---

## Що всередині

| Файл | Призначення |
|------|-------------|
| `server.js` | Бекенд (Express): посилання клієнтів, автозбереження, завантаження файлів, API адмінки |
| `schema.js` | Питання 15 розділів (для адмін-панелі) |
| `public/form.html` | Форма клієнта (той самий дизайн) |
| `public/admin.html` | Адмін-панель |
| `package.json` | Залежності |

Дані зберігаються у SQLite-файлі + завантажені файли — у теці `DATA_DIR`
(на Railway це **Volume**, тому нічого не зникає між перезапусками).

---

## Деплой на Railway (≈10 хв)

### 1. Залийте код у GitHub
Створіть новий репозиторій і завантажте туди всі ці файли (кнопкою «Add file → Upload files» прямо на github.com — без термінала).

### 2. Створіть проєкт на Railway
1. [railway.com](https://railway.com) → **New Project** → **Deploy from GitHub repo** → оберіть репозиторій.
2. Railway сам визначить Node.js і зробить `npm install` + `npm start`.

### 3. Додайте Volume (щоб дані зберігались)
1. Відкрийте свій сервіс → вкладка **Variables → Volumes** (або **New → Volume**).
2. Mount path: **`/data`**

### 4. Задайте змінні (Variables)
| Змінна | Значення |
|--------|----------|
| `ADMIN_PASSWORD` | ваш надійний пароль до адмінки |
| `DATA_DIR` | `/data` |
| `ANTHROPIC_API_KEY` | ключ Anthropic для AI-аналізу (console.anthropic.com) |
| `ANTHROPIC_MODEL` | *(необов'язково)* модель, напр. `claude-sonnet-5` |

`PORT` Railway підставляє автоматично — його задавати не треба.
Без `ANTHROPIC_API_KEY` усе працює, крім кнопки AI-аналізу.

### 5. Відкрийте доступ
Сервіс → **Settings → Networking → Generate Domain**. Отримаєте адресу типу
`https://ваш-проєкт.up.railway.app`.

### 6. Готово
1. Зайдіть на `https://…railway.app/admin` → введіть `ADMIN_PASSWORD`.
2. Створіть клієнта → скопіюйте посилання → надішліть.
3. Відповіді й файли з'являться в панелі; кожен файл можна завантажити.

## Локальний запуск (за бажанням)
```bash
npm install
ADMIN_PASSWORD=test DATA_DIR=./data npm start
# http://localhost:3000/admin
```

## AI-аналіз і збереження
- У картці клієнта є кнопка **«Згенерувати»** — AI читає бриф, знаходить прогалини
  (порожні й поверхові поля) і дає **питання для продуктового дзвінка**: що спитати
  клієнта, чого він не розкрив. Результат зберігається в базі.
- **Експорт:** «Експорт усіх (JSON)» на головній + «Завантажити .md» у кожного клієнта
  (бриф + AI-питання одним файлом — зручно віддати РОПу чи закинути в Google Drive/Notion).
- Дані лежать у SQLite на Volume — не зникають між деплоями. За бажанням далі можна
  додати авто-синхронізацію в Google Sheets (потрібен сервісний акаунт Google).

## Нотатки
- Питання розділів дублюються у `schema.js` і в `public/form.html` (масив `S`).
  Якщо змінюєте формулювання — правте в **обох** файлах, зберігаючи порядок
  розділів і полів (від нього залежать ключі збережених відповідей).
- Ліміт розміру одного файлу — 50 МБ (змінюється в `server.js`).
- Railway безкоштовний лише на пробний період; далі — тариф Hobby (~$5/міс).
- Це перша робоча версія. Якщо під час білду щось впаде — надішліть лог, підправимо.
